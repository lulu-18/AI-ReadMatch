# 线上问卷搭建与发布清单

更新时间：2026-08-02
项目：ReadMatch

## 推荐搭建方式

优先使用腾讯问卷的 PC 端“调查”场景。

本项目最省事的路径是：

1. 新建 → 调查；
2. 选择“批量编辑”，将 `questionnaire.md` 中的题目和选项复制进去；
3. 逐题确认题型、必答/选填和跳转逻辑；
4. 预览并做测试答卷；
5. 小规模试填后再正式发布。

如果你愿意先把问卷整理成 Word 文档，也可以使用“文档创建（AI 创建）”，但生成后必须逐题人工检查，不要直接发布。

## 问卷基础设置

- 标题：小说找书与推荐体验问卷
- 预计时长：5—8 分钟
- 研究说明：复制 `questionnaire.md` 的“表单开场页”
- 结束语：复制 `questionnaire.md` 的“表单结束语”
- 不收集姓名、手机号、微信号、QQ 号、账号密码等非必要信息
- 不要求上传完整小说正文
- 第 0、2、3、5、7、8、10、12、13、16、17、18、22、23、24 题设置为必答；其余题目均允许跳过
- 开放题不要设置为必答
- 不要把后续联系人的联系方式放进同一份问卷

## 题型设置对照

| 文档标记 | 平台题型 | 设置 |
|---|---|---|
| 必答，单选 | 单选题 | 开启必答 |
| 必答，多选 | 多选题 | 开启必答；如标注最多选 N 项，设置最多选择数 |
| 单选 | 单选题 | 根据研究需要设为必答或选填 |
| 多选 | 多选题 | 根据研究需要设为必答或选填 |
| 选填，简答 | 单行文本题 | 不设置必答 |
| 选填，长答 | 多行文本题 | 不设置必答 |

## 必答题设置

为保留足够的行为证据，同时避免把开放题和敏感题设置为必答，保留以下 15 道核心题：

- 第 0 题：研究同意；
- 第 2 题：阅读频率；
- 第 3 题：主要阅读类型；
- 第 5 题：发现新书的方式；
- 第 7 题：最近是否主动找书，用于分流；
- 第 8 题：开始找书的原因；
- 第 10 题：决定开始阅读前查看的信息；
- 第 12 题：最终读到的程度；
- 第 13 题：继续阅读的原因；
- 第 16 题：最近是否弃书，用于分流；
- 第 17 题：弃读位置，仅在第 16 题选择“有”时显示；
- 第 18 题：弃读或踩雷原因，仅在第 16 题选择“有”时显示；
- 第 22 题：喜欢的小说描述词；
- 第 23 题：不喜欢的小说描述词；
- 第 24 题：明确避开的内容。

第 17、18 题虽然设置为必答，但只对有弃书经历的用户出现。第 1、4、6、9、11、14、15、19、20、21、25—42 题均设置为选填，尤其不要强制用户填写开放题、AI 使用经验或隐私相关内容。
## 建议分页

- 第 1 页：同意与阅读背景（第 0—6 题）
- 第 2 页：最近一次找书行为（第 7—15 题）
- 第 3 页：最近一次弃书或踩雷（第 16—21 题）
- 第 4 页：偏好与避雷表达（第 22—27 题）
- 第 5 页：现有推荐体验（第 28—32 题）
- 第 6 页：AI 推荐与隐私（第 33—39 题）
- 第 7 页：选填补充与结束（第 40—42 题）

## 必须设置的逻辑

### 1. 同意题

第 0 题：

- 选择“同意” → 继续；
- 选择“不同意” → 直接结束问卷。

### 2. 最近一次找书

第 7 题：

- 选择“没有，不记得了” → 跳到第 16 题；
- 其他选项 → 继续第 8—15 题。

### 3. 最近一次弃书

第 16 题：

- 选择“有” → 继续第 17—21 题；
- 选择“没有”或“不记得了” → 跳到第 22 题。

### 4. 年龄筛选（可选）

如果你决定本轮只收集成年读者：

- 第 1 题选择“18 岁以下” → 结束问卷。

如果本轮不做年龄筛选，不设置这条逻辑，只保留年龄段用于样本描述。

### 5. 后续交流

第 42 题选择“愿意”时，不要在主问卷中直接要求填写联系方式。使用单独的联系表单或单独链接，避免将身份信息和阅读偏好直接绑定。

## 预览测试用例

至少提交以下 4 份测试答卷：

### 测试 A：不同意

- 第 0 题选择“不同意”；
- 检查是否立即结束；
- 检查统计中是否能区分未完成/无效回答。

### 测试 B：没有主动找书，也没有弃书

- 第 0 题同意；
- 第 7 题选择“没有，不记得了”；
- 第 16 题选择“没有”；
- 检查是否跳到第 22 题，且没有出现第 8—15、17—21 题。

### 测试 C：有找书，也有弃书

- 第 7 题选择“找到并读下去了”；
- 检查第 8—15 题全部出现；
- 第 16 题选择“有”；
- 检查第 17—21 题全部出现。

### 测试 D：有找书，但没有弃书

- 第 7 题选择任一“有”；
- 第 16 题选择“没有”或“不记得了”；
- 检查是否从第 16 题跳到第 22 题。

## 发布前检查

- 手机端实际填写一遍；
- 题目文字没有乱码或编号错误；
- 单选题没有误设为多选；
- 多选题的最多选择数设置正确；
- 选填题没有必答星号；
- 逻辑分支没有循环或跳过错误；
- 结束页没有暴露个人联系方式；
- 先发给 5—10 人试填，不要直接大规模投放。

## 数据导出与保存

回收后建议导出两份：

1. 原始数据 CSV：保留用户实际填写内容；
2. 编码数据 CSV：用于选择题统计。

保存位置：

```text
questionnaire-responses/raw/
questionnaire-responses/cleaned/
```

原始数据只保存一份，不直接覆盖。清洗和去标识化后的文件再用于分析。

建议文件名：

```text
questionnaire-responses/raw/readmatch-pilot-2026-08-02.csv
questionnaire-responses/cleaned/readmatch-pilot-2026-08-02-cleaned.csv
```
